# 헤지메이트 2단계 통합 계획 (1~5단계)

## 범위
- 자동화(6단계) 제외
- 데이터 품질 고도화 + 지표 신뢰화 + HES 개선 + 포트폴리오 분석 연결
- CSV 표준 유지

## 공통 기준
- 실행 명령: `python3 scripts/run_data_pipeline.py`
- 위기구간: SPY + (^KS200 우선, ^KS11 대체), 20거래일 -8%
- 유니버스: 70개 고정

---

## 1단계) 기준 동결(Spec Freeze)
### 목표
문서/코드 기준선 완전 정렬

### 핵심 작업
- 출력포맷/벤치마크/위기구간/Top-N/임시 제약 기준 동결
- `데이터명세`, `데이터저장구조`, `실행방법`, 스크립트 규칙 일치화

### 완료 기준
- 규칙 충돌 문구 0건
- 실행 결과 문서와 표준 문구 100% 일치

---

## 2단계) DQ 고도화 (캘린더 기반)
### 목표
시장별 거래일을 반영한 품질 판정

### 핵심 작업
- 미국/한국/암호화폐 기대 거래일 수 기반 커버리지 계산
- DQ 결과에 `coverage_ratio_calendar` 추가

### 완료 기준
- PASS/WARN/FAIL이 캘린더 기준으로 산출
- 동일 입력 재실행 시 DQ 재현

---

## 3단계) 지표 엔진 신뢰화
### 목표
핵심 지표 정확도/결측 처리 규칙 고정

### 핵심 작업
- Vol/MDD/VaR/CVaR/Beta/상관 검증셋 구축
- 허용오차 및 결측 처리 정책 문서화

### 완료 기준
- 샘플 검증 결과 허용오차 이내
- 지표 결측 처리 규칙 문서 명시 완료

---

## 4단계) HES 고도화
### 목표
유동성 반영 강화 + 점수 재현성 확보

### 핵심 작업
- 유동성 패널티를 ADV(거래량 기반)로 교체
- 정규화/클리핑/결측 정책 확정

### 완료 기준
- HES 구성요소가 결과 리포트에 노출
- 동일 데이터 버전(data_version) 재실행 시 Top-N 동일

---

## 5단계) 포트폴리오 입력 분석 연결
### 목표
사용자 비중 입력 기준 기존 vs 제안 비교

### 핵심 작업
- 입력 검증: 합계 100%, 음수 금지, 단일자산 최대 20%
- **1:1 헷징 분석**: 단일 후보 자산을 각각 적용해 개선효과 측정
- **다자산 비율 헷징 분석**: 상위 후보 조합을 비율 조정해 개선효과 측정
- 기존 vs 제안의 CVaR/MDD/변동성 비교표 생성

### 완료 기준
- 샘플 입력 1건 이상 분석 성공
- 1:1 헷징 결과표(후보별 개선률) 생성
- 다자산 조합 결과표(상위 조합별 개선률) 생성
- 리포트에 비교표 자동 포함
- 제약 위반 시 명확한 FAIL 메시지 출력
