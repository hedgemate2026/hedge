# HedgeMate 진행상황 및 데이터 수집범위 공유용 요약

## 1. 프로젝트 한줄 요약
HedgeMate는 **개인 투자자의 포트폴리오 리스크를 줄이기 위해 헷징 후보 자산을 데이터 기반으로 추천**하는 분석 플랫폼입니다.

## 2. 현재 어디까지 완료됐나
현재 **Step1 MVP 데이터 파이프라인은 완료**된 상태입니다. 문서 기준으로 아래 5단계가 모두 완료 처리되어 있습니다.

- **Step1**: 데이터/스펙 기준 확정
- **Step2**: 데이터 품질(DQ) 캘린더 기준 반영
- **Step3**: 리스크 지표 엔진 검증 체계 반영
- **Step4**: HES(헷징 효과 점수) 고도화
- **Step5**: 사용자 포트폴리오 입력 기반 분석 연결

즉, 지금은 **데이터를 수집하고 → 지표를 계산하고 → 헷징 후보를 평가하고 → 포트폴리오 개선안을 비교하는 흐름이 한 번 끝까지 돌아가는 상태**입니다.

## 3. 실제 실행 결과
저장소 기준 최신 실행본은 아래와 같습니다.
- **실행시각(UTC)**: 2026-03-05
- **파일 생성시각(KST)**: 2026-03-06
- **data_version**: 20260305

주요 결과:
- 분석 대상 자산: **70개**
- 수집 성공: **70/70**
- 분석 기간: **2021-02-24 ~ 2026-03-05**
- 위기구간(stress) 탐지: **42일**
- 지표 검증셋: **PASS 6 / FAIL 0**
- 데이터 품질 결과: **PASS 5 / WARN 65 / FAIL 0**

즉, **실행 자체는 성공했고, 치명적인 실패 없이 결과 산출까지 완료**되었습니다.

## 4. 지금 나온 핵심 인사이트
헷징 후보 상위권에는 다음 자산들이 올라왔습니다.
- **SHY**
- **IEF**
- **TIP**
- **JNJ**
- **KO**

포트폴리오 개선 효과도 확인됐습니다.
- **1:1 최적 후보**: TLT  
  - CVaR 개선률 **10.32%**
- **다자산 최적 조합**: SHY + IEF  
  - 변동성 개선률 **19.71%**  
  - MDD 개선률 **13.69%**  
  - CVaR 개선률 **20.27%**

즉, 현재 모델은 **리스크 완화용 헷징 조합을 정량적으로 제시할 수 있는 수준**까지 와 있습니다.

## 5. 아직 남은 과제
현재 남은 핵심 이슈는 3가지입니다.
1. **시장별 거래일 정렬 정책 확정**
   - 미국/한국/암호화폐의 거래일 차이를 어떻게 맞출지
2. **기준통화 및 환율(FX) 규칙 확정**
   - USD/KRW 환산을 어떤 기준으로 처리할지
3. **실사용자 입력 연동**
   - 현재는 CSV 기반 입력이 가능하지만, 실제 서비스 입력 흐름(UI/검증)은 미완성

## 6. 종합 판단
현재 HedgeMate는 **분석 아이디어 단계는 넘었고, 작동하는 데이터 기반 MVP는 확보한 상태**입니다.  
다만 서비스화/운영화를 위해서는 **거래일 정렬, 환율 기준, 사용자 입력 연동**을 다음 단계에서 정리해야 합니다.

# 현재 데이터 수집 범위

## 1. 수집 자산 수
총 **70개 티커**를 수집합니다.

### 구성
- **한국 대표주 20개**
- **미국 대표주 20개**
- **ETF/채권/원자재/방어자산 25개**
- **암호화폐 5개**

문서 분류 기준:
- 한국 개별주 20
- 미국 개별주 20
- 코어 지수/주식 ETF 8
- 채권 ETF 6
- 금/원자재/에너지 5
- 방어/대체 섹터 ETF 6
- 암호화폐 5

## 2. 지역 범위
메타 기준 분포:
- **KR**: 21
- **US**: 42
- **GLOBAL**: 2
- **CRYPTO**: 5

## 3. 대표 예시
- 한국주식: `005930.KS`, `000660.KS`
- 미국주식: `AAPL`, `MSFT`, `NVDA`, `TSLA`
- ETF: `SPY`, `QQQ`, `VTI`, `EWY`
- 채권ETF: `TLT`, `IEF`, `SHY`, `TIP`
- 원자재/금: `GLD`, `IAU`, `DBC`, `USO`
- 방어섹터: `XLP`, `XLU`, `XLV`
- 암호화폐: `BTC-USD`, `ETH-USD`, `SOL-USD`

## 4. 수집 기간
- 기본 기준: **최근 5년**
- 데이터 부족 시: **가용 구간 기준 계산 허용**
- 최신 실행본 기준 실제 분석 구간: **2021-02-24 ~ 2026-03-05**

## 5. 데이터 주기
- **일봉(Daily)**

## 6. 수집 항목

- 티커
- 자산군
- 시가 / 고가 / 저가 / 종가
- 수정종가(adj_close)
- 거래량
- 통화
- 수집시각

## 7. 데이터 소스
- **Yahoo Finance** 중심

## 8. 현재 범위의 한계
아직 최종 확정이 안 된 부분:
- 시장별 거래일 차이 처리
- USD/KRW 환산 기준
- 운영용 입력 UI 연결
