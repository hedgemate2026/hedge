## 2. 핵심 한 줄

> 현재 HedgeMate의 가장 큰 문제는  
> **입력 자산의 약점**과 **현재 시장 상황**을 먼저 해석하지 않고,  
> 원래 방어적인 자산 후보 안에서 점수 높은 것을 고르는 경향이 남아 있다는 점이다.

## 3. 문제점과 해결법 요약표

| 우선순위 | 문제점 | 왜 문제인가 | 해결법 |
|---|---|---|---|
| P0 | 입력 자산 맞춤형 후보 선별 부족 | TSLA, KO, 포트폴리오를 넣어도 비슷한 안전자산이 반복 추천됨 | 후보 선별 단계부터 `입력 자산과의 관계`를 반영. downside corr, downside beta, drawdown 동행성, stress 상대방어력을 prefilter에 넣기 |
| P0 | 시장 상태 / 시나리오 분석 부재 | 전쟁, 금리, 인플레, 지정학 같은 “지금 장세”가 추천에 직접 반영되지 않음 | `금리상승`, `인플레`, `지정학`, `경기둔화`, `KRW 약세` 같은 시나리오를 정의하고, 현재 시장의 시나리오 강도를 계산 |
| P0 | 자산별 취약점 정보가 구조화돼 있지 않음 | “이 자산은 어떤 상황에 약한가”를 체계적으로 못 씀 | 자산별 `시나리오 민감도 매핑` 도입. 단순 취약/안전이 아니라 `-2 ~ +2` 같은 점수형으로 관리 |
| P1 | 정적 hedge universe 의존 | 미리 정해진 safe haven 후보 안에서만 답을 찾게 됨 | `hedge-only`를 기본으로 두더라도 `all` 탐색 가능하게 확장. UI/API에서도 선택 가능하게 만들기 |
| P1 | 계산 지표와 추천식 사이 간극 | downside beta, KOSPI200 corr 등을 계산해도 추천에 거의 안 씀 | Gate와 최종 점수에 downside beta, downside corr, KOSPI 노출 변화, benchmark group 맞춤 노출을 반영 |
| P1 | 논리별 대표안 부재 | 결과가 “점수 1등 1개”처럼 보여 설명력이 약함 | `금리 리스크 대응`, `지정학 대응`, `경기둔화 대응`처럼 논리별 대표안을 1개씩 출력 |
| P1 | 수익 훼손 통제 미흡 | 너무 방어적이라 수익이 크게 죽는 조합도 추천될 수 있음 | Gate에 `Sharpe_improve_pct >= -5`, `연환산 기대수익 저하폭 <= 15%p` 같은 제한 추가 |
| P1 | 조합 비중 최적화 부재 | 지금은 조합 내 비중이 거의 균등이라 맞춤형 헷지가 약함 | 조합 선택과 비중 선택을 분리하고, 간단한 weight optimization 또는 grid search 도입 |
| P2 | DQ WARN 반영 약함 | 계산은 되지만 신뢰도 낮은 자산이 상위에 남을 수 있음 | WARN에도 패널티 부여. coverage, FX carry-forward, 관측치 부족 등을 신뢰도 점수로 반영 |

## 4. 시장 상태 분석 문제의 핵심 해결 구조

시장 상태 / 시나리오 분석 부재 문제는
단순히 “자산별 취약점”만 메모하는 것으로는 완전히 해결되지 않는다.

정확한 구조는 아래와 같다.

1. **시나리오 정의**
   - 금리상승
   - 인플레이션
   - 지정학 리스크
   - 경기둔화
   - KRW 약세

2. **자산별 시나리오 민감도 매핑**
   - 각 자산이 어떤 시나리오에 취약한지 / 수혜를 보는지 점수화
   - 예: `-2 ~ +2`

3. **현재 시장 상태 점수 계산**
   - 지금 금리상승 국면이 강한지
   - 인플레 압력이 강한지
   - 지정학 리스크가 커졌는지

4. **기준 자산 취약점 × 현재 시나리오 강도 계산**
   - 지금 기준 자산이 어떤 리스크에 가장 노출되는지 계산

5. **후보 자산 방어력 × 현재 시나리오 강도 계산**
   - 어떤 후보가 지금 그 리스크를 가장 잘 줄이는지 평가

즉,
해결의 핵심은 아래 두 가지를 **같이** 하는 것이다.

- 자산별 민감도 구조화
- 현재 시장 상태 해석

---

## 5. 가장 먼저 해야 할 3가지

### 1순위
입력 자산 맞춤형 후보 선별로 전환

### 2순위
시장 상태 / 시나리오 분석 추가

### 3순위
수익 훼손 제한 + 논리별 대표안 구조 도입

---

## 6. 최종 한 줄 정리

> HedgeMate는 현재 **방어형 추천 엔진 v1**으로는 의미가 있지만,  
> **입력 자산의 취약점 + 현재 시장 상태를 함께 읽는 맞춤형 헷지 엔진**으로 가려면 위 문제들을 먼저 해결해야 한다.
