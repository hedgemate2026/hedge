# HedgeMate 데이터 저장 구조 v1 (CSV 표준, Step5 반영)

## 1) 권장 디렉터리 구조

```text
outputs/
  raw/
    raw_market_daily_YYYYMMDD.csv
  processed/
    features_summary_YYYYMMDD.csv
    asset_risk_sensitivity_YYYYMMDD.csv
  reports/
    dq_result_YYYYMMDD.csv
    metric_validation_YYYYMMDD.csv
    hes_components_YYYYMMDD.csv
    asset_sensitivity_summary_YYYYMMDD.md
    portfolio_input_sample.csv
    portfolio_1to1_hedge_YYYYMMDD.csv
    portfolio_multi_hedge_YYYYMMDD.csv
    portfolio_compare_YYYYMMDD.csv

docs/STEP_1/
  04_실행결과/
    01_실행결과_YYYYMMDD.md
    02_분석리포트_초안_YYYYMMDD.md
    03_결과검토_YYYYMMDD.md
```

---

## 2) 파일 네이밍 규칙
- Raw: `raw_market_daily_{YYYYMMDD}.csv`
- Features: `features_summary_{YYYYMMDD}.csv`
- 자산 민감도 CSV: `asset_risk_sensitivity_{YYYYMMDD}.csv`
- DQ: `dq_result_{YYYYMMDD}.csv`
- Metric 검증셋: `metric_validation_{YYYYMMDD}.csv`
- HES 구성요소: `hes_components_{YYYYMMDD}.csv`
- 자산 민감도 요약: `asset_sensitivity_summary_{YYYYMMDD}.md`
- 1:1 헷징 결과: `portfolio_1to1_hedge_{YYYYMMDD}.csv`
- 다자산 헷징 결과: `portfolio_multi_hedge_{YYYYMMDD}.csv`
- 기존/제안 비교: `portfolio_compare_{YYYYMMDD}.csv`
- 실행 요약: `01_실행결과_{YYYYMMDD}.md`
- 분석 초안: `02_분석리포트_초안_{YYYYMMDD}.md`
- 결과 검토: `03_결과검토_{YYYYMMDD}.md`

---

## 3) 데이터 버전 규칙
- 형식: `YYYYMMDD` (예: `20260306`)
- 의미: 해당 실행일 기준 스냅샷
- 원칙:
  - 동일 실행일 재실행 시 동일 파일명 갱신
  - raw가 존재하면 재수집 대신 재사용(동일 data_version 재현성 강화)
  - 다른 실행일은 신규 파일 생성

---

## 4) 운영 원칙
- 저장 표준은 CSV 고정
- 리포트는 실행일자별 md 자동 생성
- 스키마 변경 시 아래 문서를 먼저 갱신
  - `docs/STEP_1/02_데이터표준/01_데이터명세_v1.md`
  - `docs/STEP_1/02_데이터표준/04_자산민감도_기준서_v1.md`
- 실행방법 문서와 실제 산출 경로는 항상 일치 유지

---

## 5) 향후 Parquet 전환 조건 (현재 비범위)
- 파일 크기/처리시간이 CSV 운영 한계를 넘는 경우
- 다중 배치/대용량 백테스트로 컬럼형 저장 이득이 명확한 경우
- 전환 시점에 `v2` 저장 구조 문서로 분리 관리
