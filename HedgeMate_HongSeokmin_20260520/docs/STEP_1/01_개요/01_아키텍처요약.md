# HedgeMate 아키텍처 설계 요약

## Overview
**HedgeMate**는 개인 투자자를 위한 헷징 기반 포트폴리오 분석 플랫폼이다.  
사용자가 특정 자산을 검색하거나 자신의 포트폴리오를 입력하면, 리스크를 줄일 수 있는 헷징 자산을 데이터 기반으로 추천하고 포트폴리오 개선 피드백을 제공한다.

---

## 1. 전체 시스템 아키텍처

### 1) Frontend Layer
- 자산 검색, 포트폴리오 입력, 결과 시각화(UI)
- 추천 이유(상관 변화, 위기구간 방어력 등) 표시

### 2) API/Application Layer
- 사용자 요청 처리(검색/분석/추천)
- 인증/사용자 세션/요청 검증
- 분석 엔진 호출 및 결과 포맷팅

### 3) Quant Engine Layer
- 리스크 계산 엔진(변동성, VaR/CVaR, MDD 등)
- 헷징 후보 평가 엔진(상관·하락방어력 기반 점수화)
- 추천 엔진(포트폴리오 재구성 제안)

### 4) Data Layer
- 시계열 시장 데이터 저장소(가격/거래량/거시지표)
- 피처 저장소(수익률, 롤링 상관, 변동성 등)
- 사용자 포트폴리오/분석 이력 DB

### 5) Infra/Ops Layer
- 배치 스케줄러(데이터 갱신)
- 모니터링/로깅/알림
- 캐시 및 비동기 작업 큐(성능 확보)

---

## 2. 데이터 파이프라인

1. **수집(Ingestion)**  
   - 주식/ETF/채권/원자재/환율/금리 데이터 수집(API)

2. **정제(Cleansing)**  
   - 결측치/이상치 처리, 거래일 정렬, 스플릿·배당 보정

3. **표준화(Standardization)**  
   - 티커 통합 매핑, 통화 기준 통일, 시간대 정렬

4. **피처 생성(Feature Engineering)**  
   - 일간 수익률, 롤링 변동성, 롤링 상관, 베타, 하방리스크 지표 생성

5. **저장(Storage)**  
   - Raw/Processed 분리 저장, 데이터 버전 관리(재현성)

6. **서빙(Serving)**  
   - 분석 API가 빠르게 조회할 수 있도록 테이블/캐시 최적화

---

## 3. 헷징 분석에 사용할 주요 금융 지표

### A. 상관/분산 관련
- **Rolling Correlation**: 자산 간 동행성 변화 추적
- **Crisis Correlation**: 위기 구간에서의 상관(핵심)

### B. 리스크 관련
- **Volatility(변동성)**: 기본 위험 수준
- **MDD(최대낙폭)**: 최악 손실 경험
- **VaR / CVaR**: 극단 손실 위험 측정

### C. 민감도/방어력 관련
- **Beta / Downside Beta**: 시장/하락장 민감도
- **Sortino Ratio**: 하방 변동성 대비 성과

### D. 추천용 통합 점수(내부 지표)
- **Hedge Effectiveness Score**
  - 위기구간 손실 완화율
  - CVaR 개선율
  - 상관구조 개선폭
  - 유동성/거래비용 패널티 반영
