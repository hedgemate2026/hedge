Project: HedgeMate

Goal
개인 투자자가 자산을 검색하거나 자신의 포트폴리오를 입력하면 
헷징 관점에서 리스크를 줄일 수 있는 자산 조합을 추천해주는 플랫폼을 만들고 싶다.

Problem
초보 투자자는 포트폴리오 분산을 위해 여러 자산을 담지만 
실제 위기 상황에서는 상관이 높아져 같이 하락하는 경우가 많다.
사용자가 '어떤 자산이 실제로 방어 역할을 하는지' 데이터 기반으로 알기 어렵다.

Core Features
1. 자산 검색 → 해당 자산과 함께 보유하면 리스크가 줄어드는 자산 추천
2. 포트폴리오 입력 → 헷징 분석 후 리스크 감소를 위한 재구성 제안
3. 추천 이유를 지표 기반으로 설명 (상관, 위기구간 방어 등)

Target Users
초보 투자자 또는 개인 투자자

Expectations
이 프로젝트의 전체 기술 설계안을 제안해줘.

다음 내용을 포함해줘:

1. 전체 시스템 아키텍처
2. 데이터 파이프라인
3. 헷징 분석에 사용할 주요 금융 지표
4. 추천 알고리즘 구조
5. MVP 개발 단계
6. 필요한 데이터 소스
7. 백테스트 방법
8. 확장 가능성

코드는 아직 작성하지 말고 
'설계 문서 수준의 구조'로 설명해줘.
